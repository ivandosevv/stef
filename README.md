# stef

Stay involved while your AI codes.

stef is a local companion that shows what your agent changes and why. Follow
the workflow, inspect a saved diff, or suggest something while the agent works.
Choose major milestones, every file, all activity, or no updates. All activity
adds available tool steps and brief shared decisions, never private thinking.
Keep the view minimal or explore changes in Interactive.

Each agent and subagent starts privately with a name like **Quiet Fox 2487**,
generated locally without AI. Start a shared workspace and pass its name to
chosen agents to work together. Leaving restores your private history.

## Get started

Tell your coding agent:

> Install https://github.com/ivandosevv/stef for this project and enable it.

The agent follows [INSTALL.md](INSTALL.md), chooses your operating system and
MCP client, and installs stef in your project's `.stef` folder. Keep coding in
that project. It opens your private workflow beside the agent using the IDE's
browser when available, or a local browser link. No stef IDE extension is needed.

Portable packages target macOS, Windows, and Linux on Intel and ARM. Binary
installs need no Go, Node, or make. Some agents require their normal MCP trust,
reload, or import step. [Compatibility](docs/CLIENTS.md).

Names and local visuals make no AI calls; agent explanations may use tokens.
